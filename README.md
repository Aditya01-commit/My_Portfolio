Responsive Portfolio Website

A one-page portfolio website for Aditya Chauhan. It has a Header, Hero, About, Skills, Projects, Contact and Footer section. It was built using HTML and CSS only.

Features used:

Flexbox for the header, hero section, navigation, form buttons and footer
CSS Grid for the project cards
Media queries (mobile first)
Relative units (rem, %, vh)
Hover effects with transitions and transforms on links, buttons, cards and table rows
Keyframe animations: fade-in on sections and a colour-changing "Full Stack Developer" text
Steps to View Responsive Behavior
Open index.html in a browser (Chrome recommended).
Press F12 to open Developer Tools, then press Ctrl + Shift + M for the device toolbar.
Resize the window or choose a device and check the layout at these breakpoints:
Screen	Width	What changes
Mobile	below 768px	Header and hero stack in one column, project cards in 1 column
Tablet	768px and above	Header and hero become a row, project cards in 2 columns
Desktop	1024px and above	Project cards in 3 columns, wider section padding
